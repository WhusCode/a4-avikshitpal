## Circle Survivors

Hosting link: http://a4-charlieroberts.me

### Goal: 
Survive waves of enemies and score as many points as you can


### Challenges: 
Implementing the parameters were the hardest part, I had to make game.js update parameters based on the inputs taken from index.html

### Controls: 
- Movement: WASD
- ESC key to pause the game and be able to change 4 parameters: 
- - Player speed
- - Enemy speed
- - Player's fire rate per second
- - Enemy spawn time interval (NOTE: this updates once the game has been reset, aka when the player dies)
- if at many moment you feel like you're stuck, just click any mouse button on the screen
